# LifeFlow
Bu proje; sadece temel veri işlemlerini (CRUD) değil, aynı zamanda konum bazlı filtreleme, kan grubu uyum algoritmaları ve rol tabanlı yetkilendirme (RBAC) gibi kritik iş kurallarını (business logic) bünyesinde barındırır. Modern IT altyapısı ile sosyal sorumluluk bilincini bir araya getirerek, acil kan ihtiyaçlarında saniyelerin önemini vurgular.
